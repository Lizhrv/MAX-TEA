# MAX TEA — Sitio web

Página web de **MAX TEA**, bebida de té natural (té negro sabor durazno con jengibre), presentación de 600 ml.

## Contenido

- `index.html` — Estructura de la página (inicio, producto, nosotros, nutrición, contacto).
- `styles.css` — Estilos con la paleta de la marca (verde, crema y dorado).
- `script.js` — Menú móvil y animaciones de aparición.
- `image/` — Logo e imágenes del producto.

## Cómo verla

Abre `index.html` en cualquier navegador, o usa un servidor local:

```bash
# Python
python -m http.server 8000
# luego visita http://localhost:8000
```
